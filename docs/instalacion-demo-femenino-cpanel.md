# Demo Femenino aislada

Paquete generado por `tools/build-female-demo-package.ps1`.

## Instalación privada

1. Respaldar `public_html/apdb-2027-prueba/demo-femenino/` si ya existiera.
2. Crear `public_html/apdb-2027-prueba/demo-femenino/`.
3. Mantener la protección de Directory Privacy del nivel superior.
4. Extraer el ZIP dentro de esa carpeta.
5. No subir ni reemplazar `.htaccess`; el ZIP no lo contiene.
6. Abrir `/apdb-2027-prueba/demo-femenino/`.
7. Verificar el aviso, seleccionar Femenino, entrar en Asociación > Competencia y ejecutar el recorrido sintético.

## Reversión

Eliminar únicamente la carpeta `demo-femenino` y restaurar su respaldo. No tocar la raíz de `apdb-2027-prueba`.

La demo contiene únicamente datos ficticios en memoria. No consulta Supabase ni publica resultados oficiales.
